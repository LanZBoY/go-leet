# 刷題 Roadmap

**模式**：長期練內功，深度 > 廣度
**節奏**：每週 3～5 小時 ≈ 2～3 題（每題含解題 + 補多解法 + 寫筆記）
**預估**：約 90 題，8～10 個月

> 時間預估是**這個深度設定下的地板，不是天花板**。
> 實際速度由每階段的「通關檢核」決定，不是由題數決定；
> 連續順利就會依「動態調整」跳題或跳階。

## 規則

- **一次只解一題**，順序由上而下，不跳階
- 一個 Stage 沒過「通關檢核」不進下一階
- 每題完成 = 自己解出 → AC → 補多解法 → 寫 `notes/` 筆記 → 打勾
- 卡超過 45 分鐘就要提示（見 `CLAUDE.md` 的 L0–L4 分級），不要硬耗
- 每個 Stage 結束寫一份 `notes/patterns/*.md` 總結該 pattern

## 動態調整

這份 roadmap 是活的，不是死清單。**每題結束後我會根據下列訊號評估要不要調整**：

| 訊號 | 判讀 | 調整 |
| :--- | :--- | :--- |
| 沒用提示就解出、複雜度一次到位 | 該 pattern 已掌握 | 同階段剩餘的同質簡單題可跳過，直接進 Hard 或下一階 |
| 只用到 L1～L2 提示 | 節奏正確 | 照原計畫走 |
| 用到 L3 才解出，且連續 2 題 | 基礎不穩 | 在當前階段插入 1～2 題更簡單的同 pattern 題補強 |
| 要到 L4（看答案） | 缺前置知識 | 停下來，先補該 pattern 的觀念或前置題，再回頭重解 |
| 邊界條件反覆錯 | 不是演算法問題，是實作精度 | 插入專練邊界的題，或加強測資的邊界案例 |
| Go 語法卡住多於演算法卡住 | 語言不熟 | 該題轉成 Go 練習，我給完整語法教學，不算在刷題進度裡 |

其他調整時機：

- 同一階段連續 3 題都很順 → 提議跳過該階段剩餘題目
- 隔了 2 週以上沒刷 → 下一題先安排同 pattern 的簡單題暖身，不要直接接 Hard
- 使用者說「這個 pattern 我想多練」→ 當場加題進該階段

**調整時我要做的事**：直接改這份檔案（加題／刪題／改順序），並在下方「調整紀錄」寫一行原因。
不要默默改，要說明為什麼。

調整紀錄見 [CHANGELOG.md](CHANGELOG.md)。
